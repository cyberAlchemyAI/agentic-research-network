# Product and research roadmap

This is a conditional roadmap, not an approved launch schedule. Durations and budgets depend on role, geography, participants, employer access and legal review. Goals refer to [PRODUCT-MODEL.md](PRODUCT-MODEL.md); phase-specific measures to the [product success scorecard](PRODUCT-SUCCESS-METRICS.md); the exact capability-to-experiment route to the [product–research trace](PRODUCT-RESEARCH-TRACE.md); gates to [AUTHORITY.md](AUTHORITY.md); experiment IDs to [EXPERIMENTS.md](EXPERIMENTS.md).

| Phase | Goal / experiments | Deliverable and exit evidence | Decision |
| --- | --- | --- | --- |

Full E08 employer value remains later. | Permit permissioned pilot expansion or redesign. |
| P3 named-role measurement | EA-G04; E01, E04, E05A-C, E07 | Select one role/level and job-task map; run separate creativity, technical-design and cooperation transfer studies plus parallel-form, rater, mode, fairness and access evidence; revise score specification. | Continue 3×10, narrow a construct, redesign a session, add cases or stop. |

| P5 product value and use | EA-G06; E08 | Candidate/employer value and cost evidence, owner-reviewed claim text and deployment controls. | Decide challenge-only, decision aid, hiring use in a named context, or no product. |

Pilot critical path: mixed audience -> reviewed cases/rubrics -> approved purpose/data protocol -> private challenge -> usability/error report. Hiring-thesis critical path remains named role/outcome -> job analysis -> role-linked cases -> measurement/transfer -> prospective outcomes -> claim decision. Case generation, UI and scoring service can be built in parallel after their interfaces are frozen. An employer pilot before P4 can collect outcomes, but its scores remain research-only unless a separate existing-law and validation basis is documented.

## Explicit branch decisions

- If Session 1 shows creative-work correlation but three cases have unstable thresholds, keep the creativity challenge and study more independent cases; the `3x10` hiring thesis is contradicted or narrowed.
- If the compact score is useful only combined with existing assessments, offer it as an incremental input with a new claim and decision study.
- If speech/video causes avoidable error, test typed or audio-only alternatives, even if that changes the original product form. Compare modes on the same construct rather than assuming equivalence.
- If future outcomes cannot be obtained across the full candidate pool, report the identification limit and avoid a broad "best engineers" claim.
- If fairness/access costs are unacceptable, pause use and redesign before further scaling.
