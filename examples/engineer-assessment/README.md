# Engineer Assessment public example source

This directory contains **88 selected candidate source files** used to construct the Network's Product 001 crosswalk. It is a source slice for modeling, not a complete Engineer Assessment implementation or a deployed assessment. The file list and hashes are in [Product 001's source manifest](../../docs/proposals/agentic-research-network/2026-10-29/model-v1/product-001-ea/source-manifest.json).

The public copy of `source/software/PRIVACY-ACCESS.md` removes controller and proposed approver identifiers from its opening status paragraph. Product 001's public manifest was regenerated from this copy. The selected sources contain no participant records; some links within them refer to files outside this deliberately limited slice.

The Product 001 model, lead marketplace, API/SDK path, engineer E rewards and W search promotion are proposals in this repository. They do not modify or activate the source Product's first MVP.
